## What is jSkid?

jSkid has three major parts:

1. **jSkript** — A simple scripting language for writing automations and mods without touching raw JavaScript.
2. **jMods** — Installable mods that run inside JanitorAI. Made by the community or yourself.
3. **jStore** — A searchable store of community mods you can install with one click.

Everything runs client-side via a userscript. No backend, no account required.
