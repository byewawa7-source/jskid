# jSkid

![CI](https://img.shields.io/badge/CI-passing-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)
![Platform](https://img.shields.io/badge/platform-JanitorAI-purple)

**jSkid** is a modern modding framework and userscript for [JanitorAI](https://janitorai.com). It gives you a scripting language (**jSkript**), a mod store (**jStore**), UI tweaks (**jTweaks**), and a powerful JS API.

## Features

- 📜 **jSkript** — readable scripting language for chat automation, mini-games, and state machines
- 🧩 **jMods** — installable mods with permission sandboxing and scoped execution
- 🏪 **jStore** — community mod marketplace with one-click install
- ⚙️ **jTweaks** — appearance, chat, performance, privacy, and notification tweaks
- 🔌 **JS API** — direct JavaScript access for power users

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/)
2. Grab the latest `jskid.user.js` from [Releases](https://github.com/byewawa7-source/jskid/releases/latest)
3. Create a new script in your userscript manager and paste the contents
4. Save, then open https://janitorai.com
